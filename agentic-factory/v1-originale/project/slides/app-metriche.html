Qui ci sono le definizioni operative delle cinque metriche e da dove prendiamo i dati. Lavoriamo con quello che il cliente ha già: Jira, la storia git e le API di review di GitHub o Bitbucket, più un breve questionario al team. Le prime due metriche seguono le definizioni DORA; la quota interna è una nostra definizione, perché non abbiamo trovato un indicatore standard pubblicato. L’acceptance rate dei suggerimenti non entra fra i KPI, perché gli stessi autori dei framework di misura lo considerano poco affidabile.
